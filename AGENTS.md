# Правила для ИИ-инструментов (Claude Code, Codex и др.)

Проект: Telegram-помощник для платформы «Альфа-Курс» (хакатон Hack&Change 2026, трек 2).
Перед работой прочитай `docs/PLAN.md` (что строим, типы и функции на границах модулей) и `docs/TEAM.md` (кто за какие папки отвечает).

## Нельзя

- Коммитить что-либо из `data/` или куски выгрузки кейса — в тесты, примеры, документацию. Репозиторий публичный, данные публиковать запрещено условиями кейса.
- Коммитить `.env`, токены и ключи.
- Передавать во внешние API персональные данные пользователя (имя, username, Telegram ID) и текст платных материалов.
- Пересказывать платные материалы в ответах бота: только краткая польза и ссылка из данных.
- Менять сигнатуры и типы из `docs/PLAN.md`, раздел 5, без согласования с командой.
- Править папки другой роли (см. `docs/TEAM.md`).
- Добавлять в коммиты строки `Co-Authored-By` и другие подписи ИИ-инструментов.

## Нужно

- Python 3.12, аннотации типов, async там, где есть ввод-вывод.
- Тест на каждое поведение: `pytest`. Тестовые данные придумывать, не брать из выгрузки.
- Время хранить в UTC, в местное переводить только при показе.
- Новая зависимость — с точной версией в `requirements.txt`.
- Новая переменная окружения — сразу в `.env.example` и README.
- После изменений `docker compose up --build` должен работать.
- Коммиты небольшие, сообщение в формате `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`.
- Тексты бота — на русском, простым языком, без канцелярита.
