# Инструкции для ИИ-агентов (Codex, Claude Code)

Этот файл читает Codex; `CLAUDE.md` подключает его для Claude Code через `@AGENTS.md`. Правила пишем только здесь.

## Проект

Прототип ИИ-помощника для предпринимателей в Telegram для платформы «Альфа-Курс» (Hack&Change 2026, кейс Альфа-Банка, трек 2). Бот отвечает по базе знаний, подбирает материалы под бизнес пользователя и напоминает об обучении и налоговых сроках. Дедлайн — 16.11.2026.

План команды: [`docs/team-plan.md`](docs/team-plan.md). Требования и ограничения кейса: [`docs/product/scope.md`](docs/product/scope.md). Архитектура и сигнатуры: [`docs/architecture.md`](docs/architecture.md). Устройство выгрузки: [`docs/data.md`](docs/data.md).

## Жёсткие ограничения кейса

- Данные кейса публиковать нельзя: ничего из `data/` и никаких кусков выгрузки в тестах, примерах и документации. Репозиторий публичный.
- Платные материалы не пересказываем: только краткая польза и ссылка из данных. Текст платных уроков не попадает ни в индекс, ни в LLM.
- Во внешние API — только нужные фрагменты, без персональных данных (имя, username, Telegram ID).
- Бот не навязчив: сам пишет только то, о чём пользователь попросил; у каждого напоминания есть «Отключить».
- Запуск одной командой `docker compose up --build`; версии зависимостей зафиксированы.
- Секреты не коммитим; переменные окружения описываем в `.env.example` и README.

## Стек

| Часть | Технологии |
| --- | --- |
| Бот | Python 3.12, aiogram 3 (long polling) |
| База знаний | чтение дампа через `pgdumplib`, поиск BM25, стемминг `snowballstemmer` |
| Хранилище | PostgreSQL 16 (сервис `db` в compose), драйвер `asyncpg`, схема в `app/storage/schema.sql` |
| LLM | OpenAI-совместимый API: `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` |
| Инфраструктура | Docker, Docker Compose, pytest |

## Кто за какие папки отвечает

| Папка | Роль |
| --- | --- |
| `app/kb/`, `app/assistant/`, `app/llm/`, `app/models.py`, `app/config.py` | 1. База знаний и ответы |
| `app/bot/`, `app/reminders/`, `app/storage/`, `app/main.py`, `Dockerfile`, `compose.yaml` | 2. Бот и напоминания |
| `app/recs/`, `app/profile/`, `app/events.py`, `eval/`, `docs/`, `README.md` | 3. Продукт, рекомендации, QA и документация |

Не правьте чужие папки без согласования с владельцем.

## Правила

- В `main` — только через PR, ветки `feat/<задача>` или `docs/<тема>`. Один PR — одна задача.
- Типы из `app/models.py` и сигнатуры из `docs/architecture.md` меняются только отдельным PR с упоминанием тех, кого это касается.
- Время храним в UTC (`timestamptz`), в местное переводим только при показе.
- Запросы к базе — только через `app/storage/`; SQL с параметрами `$1`, без склейки строк. `schema.sql` применяется при каждом старте, поэтому команды в нём повторяемые (`IF NOT EXISTS`).
- Логика без ввода-вывода — чистые функции, на каждое поведение есть тест. Тестовые данные придумываем.
- Тексты бота — на русском, простым языком, без канцелярита и без терминов без объяснения.
- Новая зависимость — с точной версией в `requirements.txt`.
- В коммиты не добавляем `Co-Authored-By` и другие подписи ИИ-инструментов.
- Сообщения коммитов: `feat: ...`, `fix: ...`, `docs: ...`, `test: ...`.

## Команды

```bash
cp .env.example .env                 # один раз, затем вписать TELEGRAM_BOT_TOKEN
docker compose up --build            # бот и PostgreSQL; выгрузка должна лежать в data/

pip install -r requirements-dev.txt  # для тестов без Docker
pytest                               # тесты на настоящей выгрузке пропускаются, если data/ пуста
```
