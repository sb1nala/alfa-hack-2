# Альфа-Курс: ИИ-помощник для предпринимателей в Telegram

Решение кейса Альфа-Банка на Hack&Change 2026, трек 2.

Бот отвечает на вопросы по базе знаний «Альфа-Курса», подбирает материалы под бизнес пользователя и напоминает об обучении и налоговых сроках.
