# Альфа-Курс: ИИ-помощник для предпринимателей в Telegram

Решение кейса Альфа-Банка на Hack&Change 2026, трек 2.

Бот отвечает на вопросы по базе знаний «Альфа-Курса», подбирает материалы под бизнес пользователя и напоминает об обучении и налоговых сроках.

> **Статус:** бот запускается в Docker, находит фрагменты в базе знаний и отвечает по ним через языковую модель: отвечает, уточняет или честно говорит, что в базе этого нет. Профиль, рекомендации и напоминания ещё не реализованы.

## Запуск

1. Создайте бота в Telegram у @BotFather и получите токен.
2. Скопируйте `.env.example` в `.env` и впишите токен в `TELEGRAM_BOT_TOKEN`.
3. Положите файл выгрузки `alfa_course_hackathon.backup` в папку `data/` — без него бот не запустится.
4. Запустите:

```bash
docker compose up --build
```

Поднимаются два контейнера: `db` (PostgreSQL, данные бота хранятся в томе `db_data`) и `bot`. Первый запуск занимает 15–30 секунд: бот ждёт базу, читает выгрузку и строит индекс. Затем напишите боту `/start` и вопрос о бизнесе — он пришлёт подходящие материалы.

Тесты без Docker:

```bash
pip install -r requirements-dev.txt
```

```bash
pytest
```

## Входные данные

Выгрузка «Альфа-Курса» выдаётся участникам хакатона и в репозиторий не входит: условия кейса запрещают её публиковать. Файлы кладутся в папку `data/`.

Используется один файл — `alfa_course_hackathon.backup` (дамп PostgreSQL). Какие таблицы и поля читает бот — в [docs/data.md](docs/data.md).

## Внешние сервисы

**Telegram.** Токен бота выдаёт @BotFather (команда `/newbot`). Впишите его в `TELEGRAM_BOT_TOKEN`.

**Языковая модель.** По умолчанию — YandexGPT через Yandex AI Studio (OpenAI-совместимый API, адрес `https://ai.api.cloud.yandex.net/v1`). Как подключить:

1. Зарегистрируйтесь в [Yandex Cloud](https://yandex.cloud/) и создайте каталог.
2. Создайте сервисный аккаунт с ролью `ai.languageModels.user`.
3. Создайте для него API-ключ с областью действия `yc.ai.languageModels.execute`.
4. Впишите в `.env`: ключ — в `LLM_API_KEY`, идентификатор каталога — в `LLM_PROJECT`, модель — в `LLM_MODEL` в виде `gpt://<идентификатор каталога>/yandexgpt/latest`.

Подойдёт и любой другой сервис с OpenAI-совместимым API: поменяйте `LLM_BASE_URL`, `LLM_API_KEY` и `LLM_MODEL`.

Без ключа бот тоже работает: вместо связного ответа присылает найденные в базе знаний материалы.

В модель уходят только вопрос пользователя, последние реплики диалога и найденные фрагменты открытых материалов. Имя, username и идентификатор пользователя не передаются; тексты платных уроков в индекс не попадают.

## Порты и зависимости

Порты наружу не открываются: бот сам опрашивает Telegram (long polling), а PostgreSQL доступен только боту внутри сети Docker (порт 5432 не публикуется). Зависимости с версиями — в `requirements.txt`, образ базы — `postgres:16-alpine`.
