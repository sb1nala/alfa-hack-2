# Альфа-Курс: ИИ-помощник для предпринимателей в Telegram

Решение кейса Альфа-Банка на Hack&Change 2026, трек 2.

Бот отвечает на вопросы по базе знаний «Альфа-Курса», подбирает материалы под бизнес пользователя и напоминает об обучении и налоговых сроках.

> **Статус:** бот запускается в Docker и на вопрос находит материалы в базе знаний. Ответы языковой модели, профиль, рекомендации и напоминания ещё не реализованы.

## Запуск

1. Создайте бота в Telegram у @BotFather и получите токен.
2. Скопируйте `.env.example` в `.env` и впишите токен в `TELEGRAM_BOT_TOKEN`.
3. Положите файл выгрузки `alfa_course_hackathon.backup` в папку `data/` — без него бот не запустится.
4. Запустите:

```bash
docker compose up --build
```

Первый запуск занимает 15–30 секунд: бот читает выгрузку и строит индекс. Затем напишите боту `/start` и вопрос о бизнесе — он пришлёт подходящие материалы.

Тесты без Docker:

```bash
pip install -r requirements-dev.txt
```

```bash
pytest
```

## Входные данные

Выгрузка «Альфа-Курса» выдаётся участникам хакатона и в репозиторий не входит: условия кейса запрещают её публиковать. Файлы кладутся в папку `data/`.

Используется один файл — `alfa_course_hackathon.backup` (дамп PostgreSQL). Какие таблицы и поля читает бот — в [docs/data.md](docs/data.md).
