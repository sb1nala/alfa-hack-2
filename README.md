# Альфа-Курс: ИИ-помощник для предпринимателей в Telegram

Решение кейса Альфа-Банка на Hack&Change 2026, трек 2.

Бот отвечает на вопросы по базе знаний «Альфа-Курса», подбирает материалы под бизнес пользователя и напоминает об обучении и налоговых сроках.

> **Статус:** готов каркас — бот запускается в Docker и отвечает заглушкой. Ответы по базе знаний, профиль, рекомендации и напоминания ещё не реализованы.

## Запуск

1. Создайте бота в Telegram у @BotFather и получите токен.
2. Скопируйте `.env.example` в `.env` и впишите токен в `TELEGRAM_BOT_TOKEN`.
3. Положите файл выгрузки `alfa_course_hackathon.backup` в папку `data/` (пока не используется).
4. Запустите:

```bash
docker compose up --build
```

Напишите боту `/start`, затем любой текст — он ответит заглушкой.

Тесты без Docker:

```bash
pip install -r requirements-dev.txt
```

```bash
pytest
```
