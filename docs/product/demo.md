# Сценарий демо

Живой показ на 4–5 минут: один герой, один день, три сценария жюри подряд. Все фразы придуманы командой.

> **Готовность на 12.11.** Шаги 1–3 и 7–8 работают в `main`. Шаги 4–6 (профиль, рекомендации, напоминания) зависят от подключения модулей к диалогу и команд напоминаний — до этого показывать их нельзя. Перед записью пройти сценарий целиком и вычеркнуть то, что не работает: на демо показываем только то, что получилось три раза подряд.

## Герой

**Марина, ИП на упрощёнке, продаёт одежду на маркетплейсе второй год.** Выбрана потому, что на ней видно всё сразу: налоговый режим даёт налоговые напоминания, отрасль и опыт — персональные рекомендации, а вопросы у неё обычные для малого бизнеса.

## Подготовка

- Бот запущен заранее: первый старт занимает 15–30 секунд, на показе это пауза.
- Чистый пользователь: перед показом удалить профиль и напоминания (или `docker compose down -v` и запуск заново).
- Ключ языковой модели вписан и проверен; ответ идёт 4–10 секунд — на это время заготовлена реплика рассказчика.
- Telegram на экране крупно, уведомления других чатов выключены.
- Запасной план: запись экрана того же сценария. Если ответа нет 15 секунд — переключаемся на запись и продолжаем рассказ.
- Напоминание для шага 6 ставим на «через минуту», чтобы оно пришло во время показа.

**Финальная реплика (20 секунд).** «Каждый ответ ведёт на платформу: ссылка на источник, материал под задачу, напоминание со ссылкой. Ссылки размечены, события пишутся в журнал — после внедрения эффект проверяется A/B-тестом по покупкам и активным дням, с ограничителями по блокировкам и отключениям».

## Вопросы жюри, к которым готов каждый

На финале спрашивают любого участника, поэтому ответы знает вся команда.

| Вопрос | Короткий ответ |
| --- | --- |
| Почему бот не выдумывает? | Модель получает только найденные фрагменты базы. Если поиск ничего не нашёл — ответ «в базе нет» без обращения к модели |
| Что уходит во внешний сервис? | Вопрос, последние реплики и фрагменты открытых материалов. Имя, username и ID не уходят; тексты платных уроков не попадают даже в индекс |
| Что, если модель недоступна? | Бот не падает: присылает найденные материалы ссылками |
| Как узнаёте о бизнесе пользователя? | По правилам из его же сообщений, без модели. Факт берём только из утверждения о себе, не из вопроса |
| Откуда налоговые даты? | Из файла-календаря, правила сверены со страницами ФНС, у каждой записи ссылка на источник. Модель даты не придумывает |
| Как не надоесть? | Бот пишет сам только то, о чём попросили; у напоминания кнопки «Отключить» и «Реже»; тихие часы |
| Как докажете пользу? | A/B-тест на 4 недели: покупки и активные дни, ограничители — блокировки и отключения. Подробно — [metrics.md](metrics.md) |
| Что не успели? | Честный список — раздел «Известные ограничения» в README |
| Почему поиск по словам, а не по смыслу? | Работает без внешних сервисов, быстро и предсказуемо; качество проверяем на наборе из 40 вопросов |
