## Как работаем вместе

- Ветки `feat/<что-делаю>`, в `main` — только через PR, смотрит хотя бы один человек.
- PR маленькие, сливаем часто: лучше три раза в день, чем один большой в конце.
- `main` всегда запускается через `docker compose up --build`.
- Общие типы из `app/models.py` меняем только по согласованию.
- Перед каждым коммитом смотрим `git status`: ни `data/`, ни `.env`.
- Короткая сверка раз в день: что сделал, что мешает, что дальше.
- К финалу каждый читает чужие модули и может объяснить их (5% оценки — командное владение).
